Staff Help Guide

System Navigation

Sunrise Dental Management System version 1.0 (Advanced Programming Project)

1. Patients

Use the Patients tab to register new patients. The system automatically generates a unique Patient Number (e.g., P-0001).

2. Appointments

Book appointments for registered patients. The system features an automatic double-booking prevention mechanism using Database Triggers. You cannot book two patients for the same dentist at conflicting times.

3. Billing

Generate bills for completed appointments. The system calculates totals automatically based on treatment fees. Updates are logged in the secure Audit Log.

4. Reports

View daily revenue and generated bills. Only accessible to Admin and Receptionist roles.
